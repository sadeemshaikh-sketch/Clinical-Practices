Notice of changes

This directory's data.json is built from the Overture Maps Foundation
places dataset (overturemaps.org), which includes Foursquare OS Places data
that Overture transformed to the Overture schema (changed: 2026-03-18).

This directory changes that data further: it keeps only counselling,
psychotherapy and psychology practices in Alberta and Ontario; keeps only
name, address, phone number, website and the Overture id; reformats the
address and phone number; merges records with the same name and phone
number; removes practices that asked to be delisted; and adds an email
address and focus areas read from each practice's own website.
